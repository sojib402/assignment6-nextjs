

1.Project Name: FITLOG

2.Description: A workout library to browse, save, and manage daily exercises.FITLOG is a simple workout library app.Users can find workouts, save them, and add them to their daily plan. 

3.Technologies: Next.js, React, TypeScript, Tailwind CSS


4.5 Key Features:

   1.Browse workout library
  2.View workout details
  3.Add workouts to today’s plan
  4.Save workouts for later
  5.Sort and mark workouts as done
